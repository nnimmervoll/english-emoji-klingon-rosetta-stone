# english-emoji-klingon-rosetta-stone

Webpage emulating a Rosetta-stone-like translation across English, emojis (so even a neanderthal should be able to read it), and Klingon.
Should either animate in a rotating three-sided polygon or put selected languages side by side for easier reading.
Klingon is a WIP placeholder language, might be replaced by something else if translations in Klingon would be too limited, or other problems
might arise.
Content will be static for at least the initial stages, a simple translation of often needed phrases and expressions across the three languages.
If time and ressources allow I might add a dynamic translation entry field, re ressources esp likely needs an LLM-API for useful translations, 
I#m not sure if I want this. A static dictionary might work too, but is obviously more limited.
